# Лабораторная работа 1 — сбор информации об ОС

> **Дисклеймер.** Это учебный проект, выполненный в рамках лабораторной работы.
> Скрипт только **читает** общедоступные параметры системы, на которой его запустил
> сам пользователь, и сохраняет их в локальный файл. Он ничего не изменяет в системе,
> не требует прав администратора, не отправляет данные по сети и не предназначен
> для сбора информации о чужих компьютерах. Полученный `os_info.json` может содержать
> имя компьютера, имя пользователя и локальный IP — не публикуйте его без необходимости.

## Что делает скрипт

1. **Определяет ОС**, в которой запущен: Linux, macOS или Windows (через `platform.system()`).
2. **Собирает параметры** системы и оборудования.
3. **Сохраняет результат** в JSON-файл (по умолчанию `os_info.json` в текущей папке).

## Запуск

Нужен Python 3.8+ (рекомендуется 3.10+). Установка зависимостей не требуется.

```bash
python my_script.py                  # результат в os_info.json
python my_script.py -o result.json   # свой путь к файлу
```

Пример вывода в консоль:

```
Обнаружена ОС: Ubuntu 24.04.5 LTS
Результат сохранён в: /home/user/os_info.json
```

## Собираемые параметры

| Раздел | Параметры |
|---|---|
| `meta` | версия скрипта, дата и время сбора |
| `os` | семейство ОС, системное имя, релиз, версия, «человеческое» название; **Linux** — дистрибутив (id, имя, версия), ядро; **macOS** — версия macOS, ядро Darwin; **Windows** — релиз (10/11), номер сборки, редакция, версия обновления (например 23H2) |
| `cpu` | модель процессора, архитектура, разрядность, число логических ядер |
| `memory` | объём ОЗУ, доступно, процент занятости |
| `disk` | системный диск: объём, занято, свободно, процент занятости |
| `uptime` | время работы с момента загрузки (в секундах и в виде `ч:мм:сс`), время загрузки |
| `network` | имя компьютера, FQDN, основной локальный IP |
| `user` | имя пользователя, домашний каталог, оболочка, запущен ли скрипт с правами администратора |
| `locale` | локаль, кодировка по умолчанию, кодировка файловой системы, часовой пояс, смещение от UTC |
| `python` | версия и реализация Python, путь к интерпретатору |

Если какой-то параметр в данной ОС получить нельзя, в JSON записывается `null`
(например, `memory.available_gb` на macOS), а скрипт продолжает работу.

## Откуда берутся данные

Согласно условию, **стандартные утилиты ОС не вызываются** (нет `subprocess`,
`os.system`, `uname`, `systeminfo`, `wmic`, `sysctl`, `lscpu` и т.п.).

| ОС | Источник |
|---|---|
| Все | модули `platform`, `os`, `shutil`, `socket`, `getpass`, `locale`, `time` |
| Linux | чтение файлов `/proc/cpuinfo`, `/proc/meminfo`, `/proc/uptime`, `/etc/os-release` |
| macOS | функция `sysctlbyname()` из системной библиотеки libc через `ctypes` (не утилита `sysctl`) |
| Windows | функции WinAPI `GlobalMemoryStatusEx`, `GetTickCount64`, `IsUserAnAdmin` через `ctypes`; реестр через модуль `winreg` |

Локальный IP определяется через `connect()` UDP-сокета: для UDP это не отправляет
ни одного пакета, а лишь выбирает сетевой интерфейс по таблице маршрутизации.

## Используемые модули

Только стандартная библиотека Python: `argparse`, `ctypes`, `datetime`, `getpass`,
`json`, `locale`, `os`, `platform`, `shutil`, `socket`, `sys`, `time`, `winreg` (только Windows).

Внешние модули не используются. Можно было бы взять `psutil` (удобен для памяти,
диска и uptime на всех ОС), но все нужные данные доступны стандартными средствами,
поэтому лишняя зависимость не добавлялась.

## Проверено
